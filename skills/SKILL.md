# 星痕共鸣国服新闻插件使用说明

当用户想要查看“星痕共鸣 / Star Resonance / 星痕”国服官网新闻、公告、维护更新、活动资讯，或询问本 Bot 是否能推送星痕共鸣官网消息时，使用本插件能力。

---

## 插件能力

- 查询星痕共鸣国服官网最近新闻。
- 自动轮询腾讯 WMP 新闻接口，发现新增新闻后推送到配置的群或会话。
- 基于 `iNewsId` 去重，避免重复推送。
- 插件重启后保留已见新闻和最近新闻缓存。
- 接口失败时，手动查询可回退到最近缓存数据。
- 管理员可查看推送状态，并手动检查更新。
- 提取官网新闻详情页全文，并调用 AstrBot 已启用的默认或指定 Chat Provider 生成 AI 总结。
- AI 总结较长时可在插件内直接调用 AstrBot T2I 渲染成图片，减少群聊刷屏。

---

## 用户可用命令

### 查看最近新闻

以下命令等价，均用于查看最近的星痕共鸣国服官网新闻：

```text
星痕国服新闻
星痕共鸣国服新闻
星痕官网新闻
星痕国服公告
星痕官网公告
```

当用户说“看看星痕新闻”“星痕今天有公告吗”“查一下星痕维护公告”时，可以引导或直接使用上述命令。

### 查看帮助

```text
星痕新闻帮助
```

### AI 总结

```text
星痕新闻总结
星痕新闻总结 2
星痕新闻总结 <newsid>
星痕新闻总结 <新闻详情链接>
星痕新闻总结模型
```

说明：

- `星痕新闻总结` 默认总结最近第 1 条新闻。
- `星痕新闻总结 2` 总结最近新闻列表中的第 2 条。
- `星痕新闻总结 <newsid>` 使用新闻 ID 生成官网详情链接，提取全文后总结。
- `星痕新闻总结 <新闻详情链接>` 直接总结指定链接。
- `星痕新闻总结模型` 只列出 AstrBot 当前已启用并加载成功的 Chat Provider，不列出未启用模型。
- AI 总结只基于详情页提取出的正文，不应承诺正文外信息。
- 如果总结较长，插件会根据配置在返回消息前尝试用 AstrBot T2I 转图片；T2I 失败时会回退文本。

### 查看推送状态

```text
星痕新闻推送状态
```

返回自动轮询是否开启、轮询任务是否运行、轮询间隔、推送目标数量、已见新闻数量、缓存新闻数量、最近成功时间和最近错误。

### 手动检查更新

```text
星痕新闻检查更新
```

仅管理员可用。会立即请求官网接口，检测新增新闻，并尝试推送到配置目标。

---

## 自动推送说明

- 自动推送目标由插件配置决定，不由普通用户在对话中临时指定。
- 首次启动或缓存为空时，插件默认只建立缓存，不推送历史新闻，避免刷屏。
- 后续轮询发现新新闻时，会推送新增新闻。
- 如果没有配置推送目标，插件仍会更新缓存，但不会发送自动推送。

---

## 配置要点

常见配置项：

- `polling_enabled`：是否启用自动轮询。
- `polling_interval_seconds`：轮询间隔，默认 300 秒。
- `target_sessions`：完整推送会话列表，例如 `aiocqhttp:GroupMessage:123456789`。
- `push_groups` + `platform_name`：用群号和平台名生成推送会话。
- `default_query_count`：手动查询默认返回条数。
- `max_query_count`：手动查询最大返回条数。
- `max_push_count_per_poll`：单次轮询最多推送条数。
- `request_timeout_seconds`：请求超时时间。
- `request_proxy`：请求代理地址。
- `ai_summary_enabled`：是否启用 AI 总结命令。
- `ai_summary_provider_id`：AI 总结使用的 AstrBot Chat Provider ID。留空时使用当前会话默认模型；非空时必须是 AstrBot 已启用并加载成功的 Chat Provider。
- `ai_summary_max_article_chars`：详情页正文交给模型前的最大字符数。
- `ai_summary_t2i_enabled`：AI 总结结果过长时是否在插件内直接调用 AstrBot T2I 转图片。
- `ai_summary_t2i_threshold`：AI 总结结果达到该字符数时转图片。设为 0 表示所有总结都转图片。
- `ai_summary_prompt`：AI 总结提示词。

当用户想让插件自动推送到某个群时，应提醒管理员在 WebUI 配置 `target_sessions`，或配置 `push_groups` 与 `platform_name`。

当用户想指定 AI 总结模型时，应提醒管理员在 WebUI 配置 `ai_summary_provider_id`。该配置只能选择 AstrBot 已启用的 Chat Provider；如果留空，则使用当前会话默认模型。不要向用户列举未启用模型。

## 当前未实现能力

当前版本暂不支持以下能力，如用户询问应如实说明：

- 按分类查询 `公告 / 新闻 / 活动`。
- 查询指定数量，例如 `星痕新闻 10`。
- 群内命令开启或关闭推送。
- 刷新缓存或清空缓存命令。
- 发送新闻封面图。
- 展示新闻正文全文。

## 回复建议

用户问“星痕有新公告吗”：

```text
可以发送「星痕国服新闻」查看最近官网新闻。
```

用户问“怎么开启自动推送”：

```text
需要管理员在插件配置里开启 polling_enabled，并配置 target_sessions，或配置 push_groups 与 platform_name。
```

用户问“为什么没有自动推送”：

```text
可以先发送「星痕新闻推送状态」查看轮询是否运行、推送目标数、最近错误和缓存状态。
```

用户要求手动检查：

```text
管理员可以发送「星痕新闻检查更新」。
```

用户要求总结最新公告：

```text
可以发送「星痕新闻总结」，我会提取最新官网新闻详情页正文并调用 AstrBot 当前默认模型总结。
如果总结较长，会按配置尝试转成图片发送。
```

用户要求换一个总结模型：

```text
可以先发送「星痕新闻总结模型」查看当前 AstrBot 已启用的 Chat Provider，再由管理员在插件配置里设置 ai_summary_provider_id。
```
